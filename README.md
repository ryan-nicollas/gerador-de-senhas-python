# 🔐 Gerador de Senhas em Python

Projeto desenvolvido em Python para gerar senhas personalizadas de forma simples. O usuário escolhe as características da senha e o programa gera uma combinação com base nas opções selecionadas.

## 🚀 Funcionalidades

* Escolha do tamanho da senha
* Uso de letras maiúsculas e minúsculas
* Opção de adicionar números
* Opção de adicionar símbolos
* Verificação básica da força da senha
* Tratamento de entradas inválidas
* Geração de várias senhas

## 🛠️ Tecnologias utilizadas

* Python 3
* Biblioteca `random`
* Biblioteca `string`

## ▶️ Como executar

Clone o repositório e execute o arquivo principal:

```bash
python gerador.py
```

Depois, siga as opções exibidas no terminal para configurar e gerar sua senha.

## 📚 Sobre o projeto

Criei este projeto para praticar conceitos de Python, como funções, condicionais, loops, validação de dados e uso de bibliotecas da linguagem.

O projeto também serviu como exercício para trabalhar com geração aleatória de caracteres e interação com o usuário pelo terminal.
